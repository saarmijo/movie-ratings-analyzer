# Overview

The Movie Ratings Analyzer is a program that organizes movie information and analyzes ratings using R. It stores details about each movie, including its title, genre, release year, runtime, rating, and whether I have watched it.

I created this project to improve my programming skills and learn how to use R for working with data. I wanted to practice organizing information, writing functions, using loops, and displaying results in different ways. The program calculates the overall average rating, finds the highest-rated movie, compares ratings by genre, and creates charts to make the information easier to understand. It also uses a CSV file to save and load the movie collection.

# Development Environment

I developed this project using Visual Studio Code on a Mac. I installed R and the R extension for Visual Studio Code to write and run my program.

The programming language I used was R. I used built-in R features such as data frames, factors, character strings, integers, numeric values, logical values, functions, loops, and CSV file handling. I also used R's built-in charting functions to create a bar chart and histogram. No additional libraries were needed.
